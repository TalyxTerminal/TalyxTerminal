# TALYX 使用指南

[English](user-guide.md)

TALYX 是一个桌面应用，用于行情数据、图表、量化研究和 AI 辅助工作。它在你自己的电脑上运行：数据、代码、运行记录和对话都存在本机，行情直接从你选择的数据源获取。它由模块组成：行情（Market）、图表（Chart）、量化（Quant）、Agent 和开发工具（Developer），模块在工作区里摆放和配合；你也可以加入别人或自己写的模块。

界面上的文字用**粗体**表示，菜单写作**菜单 › 项目**。界面语言切换到简体中文后，看到的就是这里写的中文名称。

## 1. 安装和启动

**系统要求。** 64 位 Windows，需要联网。请为量化的研究环境（约 1.1 GB）、可选的深度学习环境（1.5–4 GB）和你下载的行情数据留出磁盘空间。

**安装。** 从 `github.com/TalyxTerminal/TalyxTerminal` 的 Releases 页下载 `TALYX-Setup-x64.exe` 并运行。它只为当前 Windows 用户安装，不需要管理员权限；缺少 Microsoft Edge WebView2 时会一并安装（需要联网）。从开始菜单或桌面快捷方式打开 TALYX。

**第一次启动。** TALYX 打开在**首页**：世界时钟、最近的工作区（没有时是**新建工作区**）和**社区**卡片。点**新建工作区**，从空白布局开始，再添加面板。

**量化第一次运行**时会下载并准备它的 Python 环境，约 1.1 GB，大约 6 分钟。之后的运行直接复用。

**托盘。** 关闭窗口时 TALYX 缩到系统托盘，已打开工作区里的工作照常运行。用**设置 › 退出 TALYX** 或托盘菜单退出。TALYX 在托盘里时，请从托盘图标打开：这个版本里从开始菜单再启动一次调不出窗口。

**更新。** **设置 › 通用 › 有新版本时提醒我**默认打开，TALYX 在启动时和每天一次向 GitHub 查询最新版本，不发送任何关于你的信息。有新版本时顶栏出现标记。点**更新**会下载安装包、核对 SHA-256 校验值、关闭 TALYX、安装后重新打开，你的工作区、数据和设置都保留。新版本第一次启动时显示一次更新内容。

**卸载**在 Windows 设置的“已安装的应用”里进行，你的数据会保留（见[数据和隐私](#8-数据和隐私)）。

## 2. 工作区、面板和设置

### 工作区

工作区是一组面板的布局，以及其中的一切：图表、自选、警报、量化对象、对话。已打开的工作区是顶栏上的标签，后面的 **+** 用来新建或打开已保存的工作区。点当前工作区的标签打开它的菜单：

- **添加模块…**：添加面板。
- **保存**（Ctrl+S）。关闭有未保存更改的工作区前 TALYX 会询问；不保存就关闭时，图表退回已保存的状态，从没保存过的图表会被删除。
- **重命名…**、**文件夹…**（每个工作区有自己的文件夹存放文件，可以改为已有的文件夹）、**在新窗口中打开**、**关闭工作区**。
- **复制 AI 连接地址**和**停止 AI 工作**用于 TALYX 之外的 AI 应用（见 [Agent](#6-agent)）。

关闭工作区会停止它的后台工作（下载、运行、笔记本内核、警报、Bot），确认框会列出要停下的内容。重新打开后，行情下载接着进行，模型训练从已完成的窗口接着跑；其他运行不会自动重跑。

**首页 › 工作区**列出已保存的工作区，可以**打开**、**重命名**、**创建副本**、**显示文件夹**和**删除**。副本得到图表、自选和对话的独立副本；警报和筛选留在原工作区。

### 面板

每个模块以面板的形式打开。拖动面板的标签，可以停靠到另一面板旁、拆分区域或并入一组标签。标签菜单有**关闭**、**关闭其他面板**、**最大化**和**还原**；**在此添加模块**向这一组添加面板（只有一个面板的工作区没有标签行，请用**添加模块…**）。Ctrl+Tab 在一组面板间切换，Ctrl+K 打开命令面板。

### 设置

顶栏的齿轮打开**设置**。**范围**在**全局**和**本工作区**之间切换：工作区默认跟随全局，在工作区一侧改过的项目可以**恢复为全局**。和机器或共享数据相关的设置（语言、开机启动、数据源及其密钥、通知渠道）只能全局设置。

- **通用**：**语言**（English 或简体中文；切换时窗口重新加载，未保存的改动会保留）、**涨跌颜色**（**绿涨红跌**或**红涨绿跌**，用于各处的价格、盈亏和买卖）、**登录 Windows 时启动 TALYX**、**有任务运行时保持电脑唤醒**，以及版本和更新。
- **通知**：**手机通知渠道**，支持 Telegram、飞书和 Discord，可以**发送测试通知**。图表的警报和 Agent 可以发到这里。
- **外部 AI**：TALYX 之外的 AI 应用发起过的调用。
- 下面是各模块自己的页面，如**行情数据 › 数据源**、**图表 › 通用**。

模块没能启动时，TALYX 标志和齿轮上出现橙点，设置顶部的**需要处理**写明原因并提供**重试**。

### 社区

**社区**有**发现**和**已安装**两页。**已安装**列出每个模块的面板、AI 操作和使用情况，可以**启用**、**禁用…**、**重新加载**、**卸载…**，也可以**从文件安装…**（文件夹或 ZIP）。被其他模块依赖的模块不能禁用；禁用后它的面板留在原处并说明情况。在线分享模块暂不提供。

## 3. 行情：数据源、数据和品种

所有行情数据归行情模块管理，图表、量化和 Agent 都从它读取。数据在本机只存一份，读取都从本机读，只在缺数据时联网，所以已存的数据断网也能看。行情面板有两页：**数据仓库**和**数据源**。

### 数据源和密钥

**数据源**页列出每个数据源的状态和**启用**开关。点开一个数据源，可以填写密钥和设置、**测试**、查看它**提供的数据**和**行情模块用途**，或删除它的本地数据（立即删除，没有确认）。**测试全部**约 10 秒内测完所有数据源。**设置 › 行情数据 › 数据源**改的是同一份全局设置。密钥保存后不再显示。

免费数据源：

- **Yahoo Finance**：美股和港股、ETF、指数、外汇、商品、利率；公司行动、当前行业、股本。
- **Baostock**：A 股日线（含退市股）、公司行动、按日期的行业、股本，以及沪深 300、中证 500 和上证 50 的历史成分。
- **加密交易所**：Binance、Bitfinex、Bitget、Bybit、Coinbase、Crypto.com、Deribit、Gate、HTX、Hyperliquid、Kraken、KuCoin、MEXC、OKX；K 线、资金费率、未平仓合约量等（以交易所提供的为准）。
- 名单和研究资料：Nasdaq Trader、港交所证券名单（含每手股数）、标普 500 历史成分、SEC EDGAR 财务数据（需要填联系邮箱，每次请求时发给 SEC）和 CoinGecko。

需要你自己密钥的数据源：

- **Alpaca**（免费账户）：2016 年起的美股日内 K 线，以及改名换代码记录，让改过名的公司仍是同一个品种。
- **Sharadar (Nasdaq Data Link)**，付费：美股日线和退市股名单，标普 500 里已退市、被收购的历史成分因此有价格。
- **Tushare Pro**，付费：A 股日线、指数月度权重、股本。
- **Databento**，按用量付费：所选数据集的美股 K 线（**XNAS.ITCH**、**DBEQ.BASIC**、**EQUS.MINI**、**EQUS.SUMMARY**）。

这四家可以设置**每分钟请求数**，填你所购套餐的上限，行情模块会按它控制请求节奏。**Interactive Brokers (IB Gateway)** 和 **Futu (OpenD)** 可以通过本机运行的程序提供历史数据。

行情模块对每个市场和每种数据给数据源排序（主要看历史深度），一条序列只取自一家数据源。付费数据源不能用时（例如订阅到期），自动退回下一家。

### 数据仓库

**数据仓库**按市场和数据种类分组，显示数量、日期范围、缺口、数据源和占用空间。正在进行的下载列在最上面，可以**取消**；中断的可以**继续**。打开一组查看其中的序列；选中一条序列，可以看覆盖时间线、可补的缺口、公司行动、**历史代码**、最新记录，以及**在图表中打开**。

- **获取数据**：选一个指数的成分（**标普 500 成分股**、**沪深 300 成分股**、**中证 500 成分股**、**上证 50 成分股**）或搜索品种；勾选数据种类（**日线**、**1 小时**、**1 分钟**、**公司行动**、**资金费率**、**未平仓合约量**）；选择**周期**。开始前会显示估算大小和磁盘剩余空间。只取缺少的部分；某个品种失败时附上数据源的原话，其余照常；数据源限流时，任务会说明在等哪一家，然后等待。
- **更新**／**更新全部**：把序列补到最新一根 K 线（**待更新**标记随之消失）。
- **导入**：读取一个文件夹里的 CSV 或 Parquet 文件，需要时间列和开盘价、最高价、最低价、收盘价（成交量可选）。代码取自代码列或文件名（`AAPL_1d_2024.csv` → AAPL），周期取自文件名或数据本身。点**读取**后，每个文件显示为已匹配到某个品种或**未匹配**；读不了的行逐行拒收并写明原因。导入的数据是独立的数据集，和数据源的数据并存，不会替换它。
- **导出**：把选中的序列写成 Parquet 或 CSV；股票可选**不复权**、**拆股**或**拆股及分红**。
- **删除**：删除已存的行，品种保留；下载的数据需要时会重新获取。

### 品种和代码

| 输入 | 含义 |
|---|---|
| `AAPL`、`600519.SH`、`0700.HK` | 当地上市代码 |
| `US:DASH` | 指定市场的代码 |
| `USDCNY=X` | 汇率 |
| `binance:BTC/USDT`、`okx:BTC/USDT:USDT` | 指定交易所的现货或永续合约 |
| `BTCUSDT.P`、`OKX:BTCUSDT.P` | 图表上的加密代码写法 |

搜索匹配当前代码、曾用代码、代码前缀和名称（中文名也可以）。品种改名、换代码后仍是同一个品种；同一代码先后属于不同公司时按日期分开。

行情模块只存不复权价格加公司行动，读取时再计算复权，所以拆股、分红不会改写已存的数据或已导出的文件。图表上美股、港股默认只按拆股复权，A 股默认前复权（含分红），和常见行情软件一致。

### 免费数据的限制

- **使用条款。** 数据归各数据源所有。例如 Binance 的历史数据文件按 CC BY-NC-SA 4.0 提供，限非商业用途；OKX 的数据限于你自己的个人非商业交易。TALYX 在你的电脑上直接取数，不转发数据。
- **历史深度。** 没有 Alpaca 时，美股 1 小时线约能往回两年，1 分钟线约 30 天；港股 1 小时线约 60 天；有的交易所 1 分钟线只保留几天。任何数据源都没有的部分，在图表和回测里是空的。
- **第一次取数要等**，受各家每页条数和限流的限制；取过之后从本机读。
- **实时行情。** 超出免费实时额度的品种显示为延迟；股票日内数据有数据源的发布延迟。
- **没有的数据**：订单簿历史、爆仓记录、期权隐含波动率和希腊值的历史。
- **地区限制。** 有的交易所拒绝部分地区访问（HTTP 403 或 451），行情模块照实显示，不会自动换数据源。请求遵循 Windows 的代理设置。

## 4. 图表

图表照 TradingView 设计。一个图表面板是一个布局，放 1 到 8 张图，整个工作区最多 8 张图。新面板默认打开 OKX BTC/USDT 现货日线。

- **顶部工具栏**：搜索品种、**对比或添加品种**、周期、图表类型、**指标**、**指标模板**、**警报**、**回放**、**撤销**（Ctrl+Z）、**重做**（Ctrl+Y）、**布局**（图的数量，以及**在布局中同步**代码、间隔、十字光标、时间和日期范围）、**设置**、**快照与导出**。
- **底部栏**：日期范围预设、**跳转到日期**、**时区**、**复权**（分红复权开关）、对数和自动刻度，以及**筛选器**和**编辑器**两个标签。
- **右侧栏**：**自选**、**警报**、**对象树和数据窗口**。左侧是**画线工具**，画线锚定在时间和价格上。

图表类型包括 K 线、美国线、折线、面积、基线、平均 K 线，以及砖形图、Kagi、点数图、新价线和 Range。一张图先加载最近 1 万根 K 线，往回拖动时最多加载到 3 万根。图例显示行情状态（实时、延迟、仅历史数据、已收盘、恢复中，或失败并提供**重试**）。

**指标。** **内置指标**共 43 个，另有**收藏**和**我的指标**。成交量也是指标，新图默认带上。某个指标算不出时只在它自己的图例上写明原因，其他指标照常。指标可以读取其他品种和周期（`request.security`），也可以用后缀读取行情模块的衍生数据：`_OI`（未平仓合约量）、`_FR`（资金费率）、`_MARK`（标记价格）、`_INDEX`（指数价格）。

**自己写指标。** 在**编辑器**标签里点**新建指标…**，写好后**添加到图表**。指标是由 PyneCore 运行的 Python 脚本，语义照 Pine，但不是 Pine 语言，TradingView 的 Pine 脚本不能直接粘贴运行。开发工具的帮助里有“编写图表指标”。

**自选**：每个工作区可以有多张自选列表，可分组，每张最多 200 个品种。

**警报。** 点**警报**，或价格刻度旁随十字光标移动的 **+**（**在此价格添加警报**）。目标是一条序列或一整张自选。添加 1 到 5 个条件（全部满足才触发），比较价格、指标输出、画线、常数或脚本的 `alertcondition`，运算包括穿越、大于小于、进入或离开通道、N 根 K 线内涨跌超过多少（数值或百分比）；选择触发频率（**仅一次**、**每根 K 线一次**、**每根 K 线收盘一次**、**每分钟一次**）、有效期、消息，以及**弹窗提示**、**播放声音**或**发送到手机**。新警报的默认值在**设置 › 图表 › 通用**。

警报立即生效，不随工作区保存与否改变。只有它所在的工作区打开时（包括缩到托盘）才盯盘，而且只判断实时 K 线；TALYX 没开的那段时间事后不补判。警报固定使用创建时的指标代码，之后改了指标，旧警报照旧，并标出**使用较早版本**。触发记录保留 90 天。

**筛选器**：**新建筛选**，按每个成员最新一根已收盘 K 线，用最多 5 个条件筛选一组代码或一张自选。

**模板**（指标、图表设置、画线样式）所有工作区共用。**回放**从你选的那根 K 线开始逐根前进，期间实时行情和警报照常运行。**快照与导出**可以复制或下载图像，或把当前窗口里已收盘的 K 线和各指标输出导出为 CSV、JSON 或 Parquet。

图表的改动随工作区保存；每张图在内存里保留 100 步撤销，包括 Agent 做的改动。量化的运行可以作为研究图层放到图上；图层是快照，重新运行后要再在图表中打开一次才会更新。

## 5. 量化

量化模块用于因子、模型、资产配置、策略回测、笔记本，以及发布研究成果的成果库。它只做研究：这个版本的 TALYX 不会下真实订单。

### 量化怎么组织

**首页**显示**待处理**（现在需要动手的事）、**运行中和排队中**、**新建**（各类对象的空白版或预设）和**最近更改**。**全部对象**列出所有对象及其代表性运行（已发布的那次；没有就取加星的；再没有就取最近一次成功的）；**成果库**打开成果库。对象属于创建它的工作区，列表可以在本工作区和全部工作区之间切换。

因子、模型、资产配置和策略的页面结构相同：

- **代码**：一个开发工具项目，显示在可显示、隐藏、调整大小的代码区；**在开发工具中打开**进入完整编辑器。
- **数据设置**（**设置数据**）：**品种范围**（**代码**、**研究列表**、带历史成分的**指数**，或**代码中的规则**）、复权或不复权、周期和时间范围。结束日默认是**最新收盘价**，即运行开始时数据源已发布的最后一根 K 线。
- **代码设置**来自代码（`q.param`、`q.choice`、`q.pick`、`q.table`）；**运行设置**包括本金、成本、成交、基准、留出期等。上次运行后改过的设置会标出。
- **工作页**放做决定所需的一切：设置、运行、关键数值、检查，以及和对比运行的差别。**结果**是所选运行的深入分析。Ctrl+Enter 运行。

**运行。** 运行先保存代码，再冻结代码、参数、数据和环境。运行中显示当前步骤、已用时间和已完成的部分，可以停止。失败时定位到代码里出错的那一行，附调用栈和局部变量。**运行记录**里可以**加星**、写备注、**对比**两次运行（代码和设置的差别），以及**使用此版本**恢复那次的代码和设置。因 TALYX 重启而中断的运行标为中断，不会自动重跑。

**队列。** 所有运行共用一个队列：交互操作优先，批量运行和成果库更新按这台机器可用的 CPU 和内存排队。内存估计超出预算的运行会等别的跑完再单独运行；真的不够时，运行失败并写明用了多少、本机有多少。参数扫描和批量运行没有数量上限；估计超过 10 分钟的会先询问。

**检查**全站门槛一致（例如重叠修正后 t ≥ 3、和成果库已有项的秩相关低于 0.7、盈亏平衡成本至少是假设成本的 2 倍）。没通过的会标出，但不拦。

### 因子

用 Qlib 的算子加上 `CSRank`、`CSZScore`、`CSDemean`、`IndRank` 和 `Neutralize` 写公式，读取 `$close` 这类字段，用 `$lib.名字` 读成果库的值。写错时直接在公式里标出；引用未来数据的写法会被拒绝。**转为代码**把公式转成 Python。

研究进程热起来以后，一次运行约 1–3 秒。**工作页**显示 Rank IC、重叠修正后的 t、扣成本后的多空收益、换手率、覆盖和与成果库最相近一项的相关；分组收益图；持有 1 到 20 天的 IC 衰减（点某一天即改用它）；检查；以及某一天的截面表，列出每个名字的输入、取值、排名和之后的收益。**结果**有**收益率**、**IC**、**行业**、**风格**、**换手率**、**成本**、**事件**和**设置**，以及**叠加到价格图**和**数值**。运行设置包括股票池过滤、持有天数、交易延迟、分组、去极值、中性化（默认按行业和对数市值）、成本（默认每笔 5 个基点）和留出期。**使用本次运行**可以不先发布就用这次运行新建模型或策略，或在笔记本中打开；**发布**把它放进成果库。

### 模型

预设有**基于 Alpha158 的 LightGBM**、**基于 Alpha360 的 LSTM** 和**基于价格风格的岭回归**。标准流程分为数据、输入（成果库的因子、Alpha158、七个价格风格、自己写的）、处理、标签（用公式写）、切分（训练、验证、测试窗口，扩展或滚动，多久重训一次）和算法（LightGBM、XGBoost、CatBoost、线性模型、DoubleEnsemble 等，另有 18 种神经网络）。

**仅检查**几秒内完成发出前检查：每个窗口的样本数、覆盖、高度相关的输入、未来数据和内存，并在时间轴上画出各窗口。给任一设置指定多个值，就成了一批训练。实验表列出每次训练，默认按测试集 Rank IC 排序；选中几行点**组合运行**取平均。训练可能要几个小时，需要 TALYX 开着；重启后从已完成的窗口接着训练。神经网络需要深度学习环境（PyTorch，CPU、NVIDIA CUDA 或 Intel XPU 版本），选中时会提示安装。

### 资产配置

标准流程包括资产池、目标（等权、反波动、最小方差、风险平价、风险预算、层次风险平价、最大比率、跟踪基准等）、风险估计、约束、调仓日历和按资产类别的成本。**工作页**显示本期权重和风险占比（对照已发布的那一版）、历次调仓权重的堆叠图、对照 60/40 和等权的关键数值，以及本期的调仓清单。改一项设置，约 1 秒内重算本期；**运行回测**跑整段历史。资产池可以跨市场：收益可按周或按月对齐，其他币种按汇率换算成美元，历史较短的资产可以借用代理资产的早期价格。已发布配置的新一期可以复核：**采用计算结果**、**作为本期的一次性调整应用**，或改方法后发布新版本。

### 策略和回测

策略是用 `q.Strategy` 写的 Python 代码，由 NautilusTrader 引擎运行。预设有**按信号取前 N 名**、**按权重调仓**、**单品种信号策略**、**BTC 突破**和**均线交叉**。

运行设置包括：本金、交易所条件（杠杆、保证金、强平、止损触发方式、持仓模式，只在适用时出现）、成本、**成交时点**（默认**下一根 K 线开盘**，也可选**下一根 K 线收盘**）、做空、基准、无风险利率、撮合用的更细 K 线、限价单成交规则和停牌处理。默认基准按市场：美股 SPY、A 股沪深 300、港股盈富基金 02800.HK，加密为所交易品种的买入并持有；也可以填任何代码。无风险利率默认：美股和港股用 13 周美国国债利率，A 股固定年化 4%，加密为 0。

成本包括手续费、半点差、冲击成本、融券费和永续合约资金费。手续费按品种取自行情模块；交易所名单里没有费率时，使用它公布的普通用户标准费率，并标为假设值。代码下单按整手向下取整：A 股按 100 股（卖出时剩下的零股随最后一手一起卖出），港股按每只股票的每手股数。

**工作页**显示年化收益、最大回撤、夏普比率、超额收益、每年成本和交易笔数；带成交点的净值与价格图（多个品种时从贡献列表里选）；调仓记录、持仓、交易和日志。**结果**包括统计、月度和年度收益、回撤、多空两侧、按品种和行业的盈亏、成本、容量、危机时期、订单、账户和风格。

**参数扫描**对参数或运行设置做网格运行，结果是热力图；**使用这些值**把某一格的值写回。TALYX 标出最好的一格，但不替你选。**滚动验证**在每个窗口挑出最好的组合，再用它跑之后的月份。检查包括留出期夏普比率、滚动验证效率、相邻组合、成本翻倍、随机打乱交易顺序、前五名交易的占比，以及按尝试组合数打折后的折减夏普比率。

### 留出期

在**运行设置**里设置留出期的起点后，因子、模型、资产配置和策略的普通运行都停在它之前。**在留出期验证…**是单独的一种运行：确认框会写明这段代码和这段留出期已经验证过几次，结果和样本内的数字并排显示。看过留出期再改，它就不再是样本外了。

### 笔记本

笔记本用起来像 JupyterLab，侧栏有变量和成果库，支持 `input()`、`%debug` 和 ipywidgets，内核运行在研究环境（Python 3.12）或深度学习环境里。常用入口：`q.data(...)`（一组代码、研究列表或指数的 K 线，默认按拆股和分红复权）、`q.run(run_id)`、`q.backtest(...)`（记为该策略的一次运行）、`q.library.read(名字)`、`q.model(名字)`。停止输入几秒后自动保存。**提取为新对象**把选中的单元格变成一个对象；每次运行都可以在笔记本中打开。在同一面板里切到别的页面时内核继续运行；关闭面板或工作区时停止，若有单元格在运行会先询问。超过 2 MB 的单个输出不保存。

**软件包**（在 **…** 菜单里）向研究环境（Python 3.12）和策略环境（Python 3.13）安装 Python 包，不改动 TALYX 自带的版本；有冲突时写明是哪个包。装好后重启内核才能用上。各对象共用的代码放在公共代码文件夹（**打开公共代码**）。

### 成果库

成果库存放已发布的因子、模型和资产配置，以及笔记本发布的一次性数据。发布从一次已完成的运行开始：版本自动编号，没通过的检查会列出；TALYX 会在三个较早的截断点重算取值，有任何一个值变了，说明代码用到了未来数据，发布会被拒绝，并写明品种和日期。打开**自动更新**后，只要 TALYX 在运行，每个版本每期都会产出新值。成果库列出每一项的状态（如按时、延迟、缺失、失败、已停止）、最近 20 期、发布时和发布后的表现，以及谁在用哪个版本。**以此新建**用它新建对象，并固定在这个版本上。策略按每个值实际可得的时间读取；发布新版本后，用旧版本的对象是否换新由你决定。

### 量化怎样处理数据

- 价格默认按拆股和分红复权，锚定在最新一天，所以早年的复权价不是当时的成交价。按绝对价位比较（如“股价低于 5 元”）时请用**不复权**。
- 价格中途断掉的股票（退市，或数据源之后没有数据）按最后一根收盘价退出，运行的数据说明里会点名。
- 因子研究中，停牌的股票不进当天的截面。
- 没有价格的名字会被剔除并注明（如“300 只里 3 只没有价格”）；只有一个都不剩时运行才失败。
- 指数成分按生效日期变化：标普 500，以及按 Baostock 每周名单的沪深 300、中证 500 和上证 50。
- A 股行业按当时已知的分类（每季度读取一次，变化最多晚一个季度生效）。美股、港股只有当前分类，整段历史都用它。
- 幸存者偏差：免费的美股名单只有当前上市的股票，填了 Sharadar 密钥才包括退市股；Baostock 的 A 股名单含退市股。按今天的名单回测过去，仍有幸存者偏差。
- 做空结果偏乐观：免费数据没有“哪些股票借得到”。
- 因子、模型和策略的品种要在同一个交易日历下；资产配置可以跨日历。

## 6. Agent

Agent 是在 TALYX 里工作的 AI 助手：它能看到你正在看的内容，并通过和面板相同的操作使用所有模块，例如读取行情、修改图表和警报、新建并运行量化对象、写代码和文件、搜索网页。它的面板有**对话**和 **Bot** 两种模式。

**连接模型**在**设置 › Agent › 模型**：用你自己的密钥添加服务商（OpenAI、Anthropic、Google、xAI、DeepSeek、Kimi、智谱），添加本机模型（Ollama 或 LM Studio），或添加其他兼容 OpenAI 或 Anthropic 接口的服务。请做连接测试；不能调用工具的模型无法用于 Agent。填上价格后可在**用量**里看到费用估算。

**对话。** 在输入框里输入（**@** 引用文件，**/** 使用命令），可以附加文件或图片，选择模型和思考强度。**权限**有三档：

- **只读**：更改、删除、运行代码或向外发送内容前询问。
- **自动**：删除你自己的东西前询问。
- **完全访问**：从不询问。

**计划模式**让它先提出计划，由你批准后再动手。需要批准的操作以卡片形式出现；侧栏显示子代理、任务和改动。一轮回答对文件和对象做的改动可以**撤销**和重做。**从此处编辑**改写你的某条消息，可以同时撤销之后的改动；**从此处分支**另开一个对话。Agent 的 Python 以你的 Windows 用户身份和权限运行，没有沙箱。

**Bot** 有自己的职责、模型、权限、预算和运行记录。它可以按计划运行（预设包括**盘前简报**和**每周回顾**），在图表警报等模块事件发生时唤醒，也可以在群组里协作。普通对话也能定时（**已定时**）。定时任务在工作区打开时运行；工作区关闭期间错过的，重新打开后补跑一次。后台等待批准的操作无人回应时会过期，记为没做。

**设置 › Agent** 里还有**通用**、**对话**、**Bot**、**个性化**（指令、记忆，以及可设为只读或读写的知识库文件夹）、**搜索**（模型自带的搜索、Exa，或填密钥用 Tavily）、**技能**、**知识库**、**用量**和**花费上限**（每月上限，达到后停止新的付费请求）。

**TALYX 之外的 AI 应用**，只要支持 MCP（如 Claude Code、Codex），就能使用同样的操作。在工作区菜单里选**复制 AI 连接地址**，得到绑定这个工作区的地址；Claude Code 用 `claude mcp add --transport http talyx <地址>` 添加。批准规则由外部应用自己决定。**设置 › 外部 AI** 列出它们的调用。

## 7. 开发工具：编写自己的模块

开发工具是 TALYX 的编辑器：左边是项目文件树，中间是 Monaco 编辑器；量化对象的 Python 文件有补全、跳转到定义和错误提示。切换项目的入口里有**新建 TALYX 模块**、**打开文件夹**、**从列表移除**和**移到回收站**。跨文件搜索、终端和断点调试请用**在 VS Code 中打开**（需要安装 VS Code，`code` 命令在 PATH 里，并装有 Python 扩展）；在 VS Code 里保存的改动约 1 秒内回到 TALYX。未保存的内容重启后仍在（**恢复**），**文件历史**保留早先的版本；有未保存内容时文件在磁盘上被改，会标出**磁盘版本已更改**，由你选择保留哪一份。

**编写模块：**

1. **新建 TALYX 模块**只需要名字，会在你的模块文件夹里建好一个能运行的模块，带一个操作（`greet`）和一个调用它的面板。前端是纯 JavaScript，不需要构建。
2. **在 TALYX 中使用**：像已安装的模块一样启用它，它的面板出现在**添加模块**里，操作也可供 Agent 和外部 AI 使用。
3. 改完代码点**重新加载**：保存文件，重新生成模块的契约，只重启这一个模块。
4. **在 VS Code 中调试**写好启动配置并打开 VS Code，在“运行和调试”里启动即可附加到这个模块的进程；模块重启后再点一次。

模块用 Python 声明它的操作、数据流、设置和面板；TALYX 先读声明再运行代码，其他模块和 AI 看到的就是这些声明。开发工具的帮助列出 SDK 参考资料。安装的模块在自己的进程里运行，崩溃不会影响别的模块，但这不是安全沙箱：只安装你信任的模块。

## 8. 数据和隐私

TALYX 没有账号。安装版把所有数据放在 `%LOCALAPPDATA%\TALYX\Data`：

| 内容 | `Data` 下的文件夹 |
|---|---|
| 工作区文件夹 | `workspaces\` |
| 模块数据：行情、量化运行、对话 | `modules\<模块>\` |
| 图表指标 | `module-files\chart\indicators\` |
| 量化公共代码、`requirements.txt` | `module-files\quant\common\` |
| Agent 技能 | `module-files\agent\skills\` |
| 你安装或编写的模块（代码；它们的数据在上面的 `modules\<模块>\`，卸载模块只删代码） | `installed-modules\` |

**密钥**（数据源、AI 服务商、搜索服务、通知渠道）存在 Windows 凭据管理器里，不写进文件；保存后 TALYX 只显示是否已设置。

**会离开你电脑的内容**：发往你启用的数据源的请求（遵循 Windows 代理设置）；打开更新检查时向 GitHub 的查询；你的消息和 Agent 为回答而读取的内容，发给你选择的模型服务商，搜索词发给搜索服务；手机通知；每次向 SEC 请求时附带的联系邮箱。

**升级**会把你的数据逐步转换成新版本的格式并保留。旧版本不会打开新版本写过的数据，它会说明原因，数据保持原样。卸载后 `Data` 仍保留；要彻底删除，请删掉这个文件夹以及凭据管理器里 TALYX 的条目。
